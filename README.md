# Railway Reservation System

A simple command-line Railway Reservation System built using **Python** and **MySQL**.

## Features

- Book a railway ticket
- Search for available trains
- Check the number of seats left
- Cancel an existing booking
- View active bookings
- Validate 10-digit phone numbers
- Prevent duplicate bookings on the same train
- Handle limited-seat bookings using database transactions

## Technologies Used

- Python 3
- MySQL
- MySQL Connector/Python
